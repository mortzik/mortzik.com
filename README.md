# mortzik.com

Personal website of Mortzik: electronic music producer, soundtrack composer and audio-visual artist.

A static site (plain HTML/CSS/JS) hosted on GitHub Pages at https://mortzik.com.

- `index.html`: page content (bio, music embeds, works, contact)
- `style.css`: styling
- `script.js`: animated polyrhythm background
- `images/`: photos used on the page
- `CNAME`: custom domain for GitHub Pages
